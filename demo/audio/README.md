# Demo audio (S6 voice queries)

These clips are synthetic text-to-speech placeholders generated by `scripts/make_audio.py` (edge-tts; Urdu voice
`ur-PK-AsadNeural` for V1, `en-GB-RyanNeural` for V2/V3), stored as mp3 and as 16 kHz mono wav. The V1 text is Roman
Urdu read by an Urdu voice, so it is only an approximation of real speech. Replace them with a real presenter
recording (keep the file names from `demo/scenarios.json`: `v1-ur.wav`, `v2-en.wav`, `v3-en.wav`), then run
`make record-cache` (or `scripts/record_cache.py --only voice`) to re-record the cached answers.
